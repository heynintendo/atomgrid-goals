BRD Phase 1 — Goal Setting

  • Goal sheet drafting with weightage validation (sum = 100%)
  • Shared goals with primary-owner sync
  • Manager approval flow with return-for-rework reason
  • Sheet locked on approval; admin unlock with audit trail
  • Quarterly check-ins with window-aware read/write state
  • Manager feedback on individual check-ins
  • L1 → L2 escalation engine with 7-day window-close threshold

BRD Phase 2 — Reporting

  • Completion reports (org-wide and manager-scoped)
  • Performance analytics: QoQ trend, employee × period heatmap, score distribution, manager effectiveness with org-median reference
  • Transactional audit log — every post-approval mutation paired with diff payload
  • Role-aware overview dashboards for employee, manager, and admin

Bonuses Earned

  • Microsoft Entra ID SSO (multi-tenant + personal MSAs)
  • Vercel region pinning (sin1) co-located with Neon Postgres (ap-southeast-1) — ~115ms p50 RTT vs ~1000ms on US-East default
  • Daily Vercel Cron at 02:00 UTC for L1→L2 promotion
  • Multi-recipient email fan-out — 8 templates × audience-aware bodies
  • Resend rate-limit-aware paced sends (600ms gap, <2 req/sec ceiling)
  • Time-travel admin tool — system clock override
  • Mobile-responsive throughout (375px+)
  • WCAG AA — zero critical/serious axe-core violations

Tech Stack

  • Frontend: Next.js 16.2.6 (App Router, RSC, Server Actions), React 19, TypeScript, Tailwind v4, shadcn/ui, Radix, Recharts
  • Backend: Prisma 7, Neon Postgres (ap-southeast-1), Auth.js v5
  • Services: Resend, Microsoft Entra ID
  • Infrastructure: Vercel (sin1 region), Vercel Cron, Vercel Edge Network
  • QA: Playwright + axe-core

Known Limitations

  • Single demo inbox: all transactional emails route to RESEND_TO_EMAIL for hackathon visibility; production would use user.email
  • Entra ID publisher verification deferred: consent in restricted-tenant orgs would require admin approval. Personal MSAs sign in cleanly today.
  • Vercel Hobby tier: cron limited to daily schedule
  • Org-management surfaces (Cycles, Users, Thrust areas, Shared goals) scaffolded but deferred — sidebar trimmed so judges only see live surfaces
